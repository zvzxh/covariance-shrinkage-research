# Synthetic browser / CLI examples

`risk_demo_returns.csv` and `risk_demo_prices.csv` are generated by
`shrinkage_research.risk_demo.synthetic_csv` with seed 20261006. They represent the
same four fictional assets: 125 return periods and 126 price rows including the
initial baseline. The generator uses two Gaussian factors and idiosyncratic noise.
Prices start at 100 and compound the generated simple returns. Tiny conversion
rounding differences are expected.

Weekday date labels are convenient example labels, not an exchange calendar.
These files contain no real market observations and do not support claims of
investment performance. Select the matching input type in the browser. The
recorded `results/risk_demo` uses the returns CSV and `configs/risk_demo.json`.

# 中文导读

这份作品研究一个具体问题：当变量很多、样本有限时，把样本协方差矩阵
向“共同方差、零协方差”的目标收缩，会怎样改变估计误差与矩阵条件数？

首版实现 Ledoit–Wolf（2004）的估计量，按原文第4节的部分设计运行7个情景，
每个情景模拟2,000次，保留逐次结果、误差范围和失败记录。

**范围必须说清：这是遵循原文设计的模拟子集，不是整篇完整复现，也不是
投资收益回测。** 原文的实际特征值向量和随机种子未公开；本项目明确记录
自己的谱生成与矩校准方法。原文中心表用1,000次，本项目用2,000次。

先看 [实际运行结果](../results/reference/REPORT.md)，再看
[英文README](../README.md) 的安装运行命令。普通Mac CPU即可运行，生成数据
不需要Bloomberg、CRSP、付费API或GPU。

结果中的 PRIAL 衡量“协方差估计误差相对减少多少”，**不是收益率**。
与原表接近只是参考；真正的核验包括手算案例、独立库对照、Gaussian理论风险、
矩阵性质和配对Monte Carlo标准误。

建议你最终能独立回答五个问题：

1. 为什么这里除以 `n`，而不是默认的 `n-1`？
2. 为什么样本协方差在 `p>n` 时会不可逆？
3. 收缩目标、收缩强度分别控制什么？
4. PRIAL为什么需要配对计算标准误？
5. 为什么协方差误差更小，不等于组合一定赚钱？

这是AI辅助实现与审查的作品，不能把自动生成内容直接等同于自己已经掌握。
现在提供的是可运行仓库与CI，尚未部署定时自主研究服务。

# V2 中文使用指南

这个项目现在可以直接在本地浏览器分析你已有的组合：上传收益率或复权价格，设置权重，比较三种风险估计，并用后来的观察检验估计是否偏离。它不预测涨跌，也不替你生成买卖建议。

## 三步打开

1. 在项目目录创建环境并安装：

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -e '.[app]'
   ```

2. 执行 `shrinkage-risk-ui`。
3. 打开 `http://127.0.0.1:8501`，选“合成样例”或上传自己的 CSV，点击“开始分析”。

服务仅绑定本机地址，关闭 Streamlit 使用统计；计算和上传文件留在本机进程。用完后在终端按 Ctrl-C 停止。正常使用不需要写代码或编辑 JSON；自定义权重通过资产对应的数字输入框填写。

## 什么时候有用

- **准备解释自己的组合**：看组合年化波动和风险集中在哪里，区分资产权重与风险贡献。
- **比较不同风险假设**：在样本协方差、Ledoit–Wolf 收缩、仅单资产方差之间切换观察，检查估计窗口和相关性对结论的影响。
- **检验风险估计**：每次只用过去窗口拟合，再对照后续样本的实际方差，保留可复查的记录。

默认示例是程序生成的四个虚构资产，不是真实行情，不证明策略收益或投资优势。

## 准备 CSV

第一列必须叫 `date`，日期格式 `YYYY-MM-DD`，唯一且从早到晚排列。至少两个资产列，资产名不可重复；不允许缺失值、无穷数、重复或乱序日期。程序会拒绝错误，不会偷偷排序、补值或删行。

```csv
date,Asset_A,Asset_B
2025-01-02,0.01,-0.005
2025-01-03,-0.002,0.004
```

收益率用小数：`0.01` 是 +1%，`1.0` 是 +100%；必须大于 -1。每行代表一个观察期，日频通常填每年 252 期，月频通常填 12；程序不会根据日期自动判断频率或补齐缺失交易日。

如果输入复权价格，选择“复权价格”，每个价格必须为正。程序无法核实数据供应商是否正确复权。它先用完整价格计算相邻收益，再按收益截止日和末 N 期筛选；第一行价格仅为基准。首个入选收益可能使用筛选开始日前的一行价格，报告会记录这个基准日期。至少保留两个收益期，因此价格至少需要三行。

默认等权。勾选自定义权重后输入百分比，总和必须为 100%，不允许负值；程序不会自动帮你归一化。改变输入、文件名或设置后，旧结果会清空，需要重新分析。

## 怎么读结果

三种估计都先去均值，再除以样本数 n，便于在同一口径下比较。风险贡献可以为负，代表在当前协方差估计下的对冲作用；不能把负数取绝对值。零组合方差时风险贡献比例未定义。矩阵奇异不等于组合波动一定为零。

年化波动按“每期方差 × 每年期数”开方，隐含期与期之间没有序列协方差。后续窗口的实际样本方差使用 ddof=1，是含噪声的检验代理，不是真实总体方差。末段较短时尤其容易波动。这里的检验使用固定暴露，不模拟持仓漂移、交易成本或净值。

## 保存与衔接

可下载独立 HTML 报告、配置 JSON、选中收益 CSV，以及含所有矩阵和审计记录的 ZIP。HTML 图片已内嵌，离线也可打开。

- 要重复同一次分析：使用**原始输入文件 + 下载的配置**；配置导入在高级选项里。
- 要继续做组合回测：把“选中收益 CSV”交给 [Portfolio Walk-Forward Lab](https://github.com/zvzxh/portfolio-walkforward-lab)，选择收益率输入。它已经完成价格转换和筛选，不应当再次按价格处理。
- 要检查来源：查看输入 SHA-256、筛选范围、价格基准日期、软件版本和各导出文件哈希。

原有论文模拟仍通过 `shrinkage-research --config configs/paper_subset.json --out work/paper-rerun` 运行，参考结果保留在 `results/reference`。它是 Ledoit–Wolf 2004 的设计对齐模拟子集，不是全文复现，也不是投资收益回测。

# Research queue

This is a queue of possible follow-up work, not a deployed autonomous service.
Each continuation should choose one question, commit its protocol before running,
retain all completed outcomes and report changes to the evidence boundary.

1. **Sensitivity to the population spectrum.** Freeze several independent shape
   seeds at the same first two spectrum moments. Separate observation uncertainty
   from across-spectrum variation. Do not select the closest match to Table 2.
2. **Original-design coverage.** Add more parameter points and, only after their
   formulas are independently checked, original competitor estimators. Clearly
   distinguish omitted methods from completed comparisons.
3. **Departure from Gaussian observations.** Prespecify a finite-moment heavy-tail
   model and a contamination model, then compare paired losses. These are new
   robustness experiments, not a reconstruction of the original unreported runs.
4. **Downstream portfolio extension.** Specify a separate experiment with honest
   training/test separation, feasible constraints and risk objectives. A result
   about Frobenius loss must not be renamed a portfolio-performance conclusion.

Suggested stopping rule for an agent: finish the selected protocol, retain any
negative result, obtain an independent review, and prepare a reviewable change.
Do not keep trying arbitrary configurations until one looks favorable. No paid
data, API calls, external submissions or production deployment are prerequisites.

# Changelog

## 2.0.0 — 2026-10-05

- Add a local Streamlit browser workbench with CSV upload, numeric asset weights,
  date/window controls, synthetic demo, downloadable reports and reusable configs.
- Add strict returns/adjusted-price ingestion with conversion and baseline audit.
- Compare centered sample, independently implemented Ledoit–Wolf, and diagonal
  covariance estimates; export risk contributions, spectra and conditioning.
- Add strictly past-trained rolling variance validation against a noisy future
  sample-variance proxy, with explicit partial-window handling.
- Add self-contained HTML, all result CSVs, selected returns, input/config hashes,
  ZIP exports and a CLI with atomic output creation and retained failures.
- Add mathematical, ingestion, causality, export, CLI and real AppTest coverage.
- Preserve the V1 experiment CLI, paper configuration and committed reference run.

## 0.1.0 — 2026-10-05

- Independent Ledoit–Wolf estimator and a seven-scenario design-aligned simulation
  subset, with auditable Monte Carlo uncertainty, predeclared checks and CI.
